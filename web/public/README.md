Static assets served at the site root by Vite.

- **start.mp3** — lobby loop until START is pressed (`START_MUSIC_URL`).
- **motion.mp3** — loop while the doll's head swivels (`MOTION_SFX_URL`).
- **shoot.mp3** — one-shot when the head finishes turning to RED (`DOLL_SFX_URL`).

Swap for any browser-playable mp3. Filenames are wired in
`src/RedLightGreenLight.tsx`.
